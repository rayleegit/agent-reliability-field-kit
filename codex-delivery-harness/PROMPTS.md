# Reusable Prompts

## Implement one scoped change

> Read `AGENTS.md`, `GOALS.md`, and `PLANS.md`. Restate the acceptance criterion affected by the requested change. Add or update a failing test first, implement the smallest change that satisfies it, run the documented verification commands, and append observed evidence to `harness/build-log.md`. Do not broaden scope without asking.

## Review a change

> Review the change against `AGENTS.md` and `GOALS.md`. Prioritize correctness, unsafe automation, missing adversarial cases, and unverifiable claims. Cite file and line locations. Run tests when possible. Do not rewrite the implementation unless separately requested.
